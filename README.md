# 下班小伙伴

一只在桌面上陪你等下班的橘猫。可以看下班倒计时、距离周五和发薪日的天数，以及按工作时长估算的收入。

![桌面挂件示例](preview.png)

## Windows 10 / 11 下载

[下载免安装 ZIP（v1.4）](https://github.com/8164-CC/offwork-buddy/releases/download/v1.4/Offwork-Buddy-Windows-v1.4.zip) · [查看发布页](https://github.com/8164-CC/offwork-buddy/releases/tag/v1.4)

下载后先全部解压到桌面或文档，再双击“下班小伙伴.exe”。按 F2 打开设置，可改上下班时间、午休、月薪和宠物。收入仅为估算。使用说明随 ZIP 提供。
